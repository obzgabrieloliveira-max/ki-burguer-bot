# Ki-Burguer — Meta WhatsApp Cloud API

1. Preencha o arquivo `.env`.
2. Execute `npm install`.
3. Execute `npm start`.
4. Publique o servidor em uma URL HTTPS.
5. Na Meta, use `https://SEU-DOMINIO/webhook`.
6. Em "Verificar token", use o mesmo valor de `META_VERIFY_TOKEN`.
7. Depois, assine o campo `messages`.
